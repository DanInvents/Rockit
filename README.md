# Rockit

Rockit (Rocket Operation Computing Kit) is a compact RP2040-based flight computer for model rockets and water rockets, developed and supported by **Triskel Instruments (formerly DanInvents)**.

## Current firmware

The current release is **Rockit Firmware 3.0**, running on MicroPython 1.29.0.

- [Firmware 3.0 release and Windows updater](https://github.com/DanInvents/Rockit/releases/tag/v3.0.0)
- [Firmware 3.0 release notes](README_Firmware_3.0.md)
- [Rockit Rev.1 User Manual - Firmware 3.0 (PDF)](Rockit_User_Manual_Firmware_3.0.pdf)
- [User manual LaTeX source](Rockit_User_Manual_Firmware_3.0.tex)
- [Rockit Rev.1 schematic](Schematic_Rockit%20Rev%201.pdf)

The standalone Windows updater is the recommended way to install Firmware 3.0. Customers do not need Python, Arduino IDE, VS Code, `mpremote`, or an external programmer.

The previous v1.6 manual remains in the repository as legacy documentation for older firmware.

## Rockit

Rockit provides barometric altitude measurement, acceleration measurement, automatic or timer-based dual-servo recovery deployment, and microSD flight-data logging.

Firmware 3.0 has been flight-tested successfully in both:

- **A - Automatic/apogee mode**
- **B - Timer mode**
